## 简介

AsylumWiki 是一个免费、开放且包容的信息聚合平台。🏳️‍🌈🏳️‍⚧️🕊️

我们致力于为那些寻求免受迫害和严重人权侵犯保护的人提供信息和资源。信息来源包括：合法获取的公共信息、授权的案例和故事，以及经过验证的专业资源推荐。

即使世界支离破碎，我们也永不放弃共同修复它。✊

## AsylumWiki是一个“违法”的网站

我们主要位于加拿大。而加拿大《移民与难民保护法》（IRPA）的的第20(1)(a)段规定，任何想要在加拿大永久居留的外国人必须要有对应的签证或许可。第124条规定任何人违反了IRPA中任何一条即属犯罪，而IRPA的第131条更是规定任何人若是引诱，**帮助**，教唆或是尝试引诱，帮助或教唆的人也属犯罪且与犯下这个人同罪。

而提出一宗难民声请就等同于是在说：“我想要永久居留在这里，因为我是一个难民。”
当然就违反了第20(1)(a)段。（这也就是为什么在加拿大一个最终没有被认可的难民声请人要被遣返的原因：
因为ta们说想永久居留在加拿大，但又没有对应的签证或者许可，在难民声请被决定之前，我们有理由相信但我们不知道一个人是不是难民，但对于一个最终没有被认可的难民声请人而言ta已经被确定为不是难民了。）

**而违反IRPA的第131条正是我们的使命**：目前互联网上关于庇护充斥着大量的不实资讯，而我们提供尽量准确，尽量可信的信息，使得一个寻求庇护者可以在知情的情况下做出一个可能改变自己人生的决定。我们提供一个详细的指引，以让寻求庇护者清楚一宗难民声请的“门槛”是怎么样的。尽管说我们不提供任何专业的意见，我们在页面中也囊括进了一些资源以帮助寻求庇护者寻求这些意见。
而我们确信，通过这些，我们可以“**帮助**”一个寻求庇护者寻求庇护，而这，本质上是违法的。

但是我们，以及难民声请人们倒不必担心：《难民公约》规定缔约国不能因为难民的非法入境和逗留而对难民施予刑罚。
同样，IRPA的第133条规定一个难民声请人不能因为ta的难民声请本身以及非法入境（如有）被刑事检控。我们尽管严格意义上说跟我们所能帮助到的难民声请人一样都是违法的，我们相信，我们**不可能**因为我们在这个网站上的所作所为而被检控，
就算是哪一天我们真的因为我们的所作所为被检控了，**如果说我们的网站能够帮助到那些有需要的人得到难民保护的话，那么我们也很高兴能够成为加拿大的“良心犯”：）**

## 原住民土地承认

我们在此承认，Asylum.Wiki 坐落于包括克莱迪特的密西沙加族、阿尼希纳贝族、奇佩瓦族、奥农达加族和温达特族在内许多民族的传统领地，被「一碟一勺」贝壳串珠合约保护的土地上。这片坐落在灵龟岛，或者许多人也称为北美大陆的土地如今仍然是许多原住民族的家园。当我们今天在此聚集时，这些民族仍在经历持续的殖民化和迁移——土地承认声明取代了土地本身的归还。

我们承认所有印第安寄宿学校幸存者、儿童被拘捕幸存者、原住民女性、被迫离开自己领土的跨性别人士、双灵人和酷儿人士，以及所有因国际殖民主义和从非洲大陆、南亚和东亚以及全球各地窃取人民、社区、劳动力和资源而流离失所的人的贡献。我们承认在加拿大、东亚以及世界各地所有继续为正义和真相而努力、反对一切形式压迫的人的贡献。我们致力于这一永远持续的工作。

## 声明

> ✉️ 我们承诺不会收集、记录或披露任何个人信息，但为了您的安全，请评估您与本项目互动的风险。我们不希望任何人面临风险。
> <br>
> 🚀 该项目的目的是通过整理公共信息、自愿案例分享以及整合相关资源推荐，消除与避难相关的信息差。
> <br>
> 💝 我们愿意讨论您的故事，但我们的意见不构成任何专业建议，包括法律和移民等。如果有必要，请寻求专业人士的帮助。
> <br>
> 🕒 由于世界的多样性、复杂性和变化性，尽管我们尽了最大努力，但我们无法对内容的真实性、可靠性和时效性负责。
