# 庇护简说

> [!CAUTION]
> **寻求庇护是一条无法回头的路**。请**务必谨慎，并独立作出决定**。**寻求庇护是一个很严肃的话题**，因为**通过难民声请留在一个国家并不是一条常规的移民路径**。
>- 和常规的“移民”（Immigrant）不同，难民之所以能留在一个国家是因为ta们**在原籍国有遭受迫害的风险**。
>- 难民声请应作为一个受迫害的人的**最后救济手段**，而非常规移民手段的替代品。
>- 在难民声请中做失实的陈述将有可能导致对难民声请的**结果不利，甚至被拒绝**。同时一个人在声请难民之后**不能**再返回原籍国，否则该人的难民声请将会被视为**放弃**/已经被认定为难民的难民身份可能会被**取消**。

寻求庇护，是寻求庇护者离开原籍国（或原居住国）的管辖区，进入另一个国家管辖区内声请被认可成为1951年《关于难民地位的公约》（以下简称《难民公约》）所界定的难民的过程。

《难民公约》对于难民的定义是：

---
>“因有正当理由畏惧由于**种族、宗教、国籍、属于其一社会团体或具有某种政治见解的原因**留在其本国之外，并且由于此项畏惧而不能或不愿受该国保护的人；或者不具有国籍并由于上述事情留在他以前经常居住国家以外而现在不能或者由于上述畏惧不愿返回该国的人。”

-[《关于难民地位的公约》](https://www.un.org/zh/documents/treaty/OHCHR-1951)

因此，根据《难民公约》，被认定为难民的人须要**同时满足**以下四个条件：
- 身处本国境外
- 有正当理由畏惧被迫害
- 畏惧由于种族、宗教、国籍、属于其一社会团体或具有某种政治见解的原因
- 由于此项畏惧而不能或不愿受该国保护

理论上来说，一个人可以在任何一个不是原籍国且已经签署了《难民公约》的国家声请成为难民，而那个国家当局在接受到声请之后会处理这些声请，但是实际上各个国家当局认不认可一个庇护声请者的程序跟标准，以至于对于难民公约的解读都不同，导致会出现寻求庇护者在一个国家不被认定为难民，在另一个国家反而被认定为难民的情况。

> [!IMPORTANT]
> 截至2011年6月，已有148个国家签署了《难民公约》或《议定书》。[难民公约签署国一览](https://zh.wikipedia.org/zh-cn/%E5%85%B3%E4%BA%8E%E9%9A%BE%E6%B0%91%E5%9C%B0%E4%BD%8D%E7%9A%84%E5%85%AC%E7%BA%A6#按英文字母排序的列表)

但如果寻求庇护者寻求庇护的国家和地区并非《难民公约》的缔约国（如香港跟泰国），那么一个寻求庇护的人就**不能**向那个国家当局提出难民声请，而是得要向[联合国难民署（UNHCR）](https://www.unhcr.org/cn/)声请，如果声请被接受，联合国难民署认可ta成为了难民的话，那么联合国难民署会把该难民重新安置到一个愿意接收ta的第三国。

> [!WARNING]
> 在这些并没有签难民公约的地方声请成为难民往往风险很大，正是因为这些地方没有签难民公约**不承认**难民和寻求庇护者的地位，只要还没有被重新安置到一个第三国，那么寻求庇护者/被认可的难民就有在声请庇护时所在的国家被该国当局**拘留**甚至是**遣返**的**风险**（[如泰国曾遣返获得正式难民身份的异见人士。](https://cn.nytimes.com/china/20151119/c19thailand/)）

一个人不可能在自己的原籍国成为《难民公约》里所定义的难民。因为《难民公约》其中一部分规定如果说一个人符合难民的定义，那么这个人必须得要在原籍国之外。一个人可能在原籍国内因为难民公约中所规定的理由在原籍国遭受过各种迫害，但是，只要ta还没有逃出本国，那么ta就不符合《难民公约》对于难民的定义，所以ta就不可能成为难民。同理一个人也不可能在一个国家驻ta原籍国的大使馆声请庇护，因为这个人还没有在国外。

## 政治/性别/人道主义庇护

> [!CAUTION]
> 由于新任美国政府的政策变动，以下的内容可能不再准确/适用/正确，我们将尽快复核并更正这些内容。

以美国为例，理论上可以通过此方式申请。不需要通过正式边检进入美国，也就是承认走线等任何方式，但从安全角度，如果申请不下美旅游签，则可以尝试申请墨西哥旅游签，然后再美墨边境申请政庇（有法案说是在等待期间要留在墨西哥，不知道有没有通过）。但谨慎选择进入的州，如果是红州可能麻烦很多。美国可以选择性别庇护。

2024 年更新：美国现任政府及可见的未来可能会对难民政策缩紧。根据拜登政府的新政策，申请庇护者必须通过 CBP One 应用程序预约入境，并且新规要求庇护申请人必须首先尝试在第三国申请庇护，否则将面临加速遣返的程序 ​。

基本上必须满足的要求：

- 在美国本土。

但最好满足如下要求：

- 有证据能够证明迫害。私以为性別多元的身分足矣，但仍需要准备证据证明中国的现状和自己的经历。
- 一年内提出申请，当母国情况巨变时此要求可放宽。

如美国的庇护相关政策可参阅如下文件，[庇护申请人资讯指南 - USCIS](https://www.uscis.gov/sites/default/files/document/guides/info-guide-prospective-asylum-applicants-chinese.pdf)。

如果被移民局驳回，则会提交至法院，败诉后可再上诉。此过程中理论上可以合法工作生活。美国的工卡会在申请后半年后发放，在此期间无法从事需要工卡的工作。

同理，许多其它国家也有类似的庇护政策，如加拿大、欧洲许多国家等。
