# 台湾

> [!CAUTION]
>
> 编者总结：台湾（中华民国）**没有**一套接收寻求庇护者的体系，赴台湾寻求庇护**无法可依**。寻求庇护者需要慎重考虑台湾这个选项。
> - 中华民国内政部虽在2005年提出《难民法草案》，历经多年朝野协商，修改多个版本，2016年在立法院联席委员会一读初审通过，**但至今仍未完成立法程序**。
> - 1987年，金门曾发生**拒绝庇护**越南船民、屠杀并毁证灭迹的"东岗惨案”。
> - 不同于韩国对待脱北者的态度，自1991年台湾终止动员戡乱后，台湾不再视中共为叛乱组织。此年起从中国大陆前往台湾的寻求庇护者中能够不被遣返回中国大陆的人数**极少**，若试图偷渡金门更会被内政部移民署依据《入出国及移民法》**拘留**并被**递解出境**。

台湾既**不是**联合国会员国，也**不是**联合国《难民公约》的缔约方。在1971年，联合国通过了[第2758号决议](https://www.un.org/zh/ga/ares2758.html)，中华人民共和国政权取代了中华民国政权在联合国的席位，自此之后，台湾以及统治台湾的中华民国政权，就没有加入过联合国；不是联合国的成员国，自然就无法加入《难民公约》，所以台湾至今都没有加入《难民公约》。

尽管说联合国的其它许多的公约都以立施行法的形式被整合进了台湾的法律体系，使得这些条约就算台湾不是缔约方这些公约也会以立法的形式实际上约束政府行使职权（比如[《身心障礙者權利公約施行法》](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0050194)、以及[《消除對婦女一切形式歧視公約施行法》](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0050175)） ，《难民公约》**并不是**其中之一。尽管说台湾的行政院在2005年有提过《难民法》的草案并且这个草案2016年在立法院进行了一读，《难民法》至今仍未完成立法程序。

总结来讲，**台湾至今为止都<u>没有</u>一套给予难民地位的体系**。
