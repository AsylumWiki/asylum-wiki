# 台湾

> [!CAUTION]
> 
> 编者总结：台湾**没有**一套接收寻求庇护者的体系，并且从中国大陆前往台湾的寻求庇护者中能够不被遣返回中国大陆的人数**极少**。寻求庇护者需要慎重考虑台湾这个选项

台湾**不是**联合国《1951难民公约》的缔约方。在1971年，联合国通过了[第2758号决议](https://www.un.org/zh/ga/ares2758.html)，中华人民共和国政权取代了中华民国政权在联合国的席位，自此之后台湾，以及统治台湾的中华民国政权，就没有加入过联合国；不是联合国的成员国，自然就没办法签《1951难民公约》所以台湾至今都没有签《1951难民公约》。

尽管说联合国的其它许多的公约都以立施行法的形式被整合进了台湾的法律体系，使得这些条约就算台湾不是缔约方这些公约也会以立法的形式实际上约束政府行使职权（比如[《身心障礙者權利公約施行法》](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0050194)、以及[《消除對婦女一切形式歧視公約施行法》](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0050175)） ，《难民公约》**并不是**其中之一。尽管说台湾的行政院在2005年有提过《难民法》的草案并且这个草案2016年在立法院进行了一读，《难民法》至今都只停留在一读的阶段没有通过。

总结来讲，**台湾至今为止都<u>没有</u>一套给予难民地位的体系**。
